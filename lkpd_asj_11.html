CyberLab Pro WireGuard VPN Server

Tujuan Praktikum

WireGuard adalah pilihan paling direkomendasikan saat ini karena konfigurasi yang jauh lebih sederhana dan performa yang lebih cepat dibandingkan OpenVPN.

  • Melakukan instalasi WireGuard pada sistem Linux.
  • Membuat pasangan kunci publik & privat (Keypair) server.
  • Membuai file konfigurasi interface WireGuard (/etc/wireguard/wg0.conf).
  • Mengaktifkan IP Forwarding dan mengizinkan Port UDP 51820 pada UFW.
  • Menjalankan service WireGuard dan menguji koneksi tunnel dari klien.

Instruksi Langkah Demi Langkah

  1. 1. Install WireGuard (Instalasi Paket Utama)

    Pasang paket WireGuard pada server Linux Anda:

    sudo apt update
    sudo apt install wireguard -y
  2. 2. Generate Public & Private Key Server

    Buat kunci kriptografi untuk autentikasi server:

    umask 077
    wg genkey | tee privatekey | wg pubkey > publickey

    💡 Catat isi privatekey dan publickey yang baru saja dibuat. (Gunakan cat privatekey dan cat publickey).

  3. 3. Buat Konfigurasi Interface Server

    Edit atau buat file konfigurasi interface WireGuard di /etc/wireguard/wg0.conf:

    sudo nano /etc/wireguard/wg0.conf 
    [Interface]
PrivateKey = <ISI_PRIVATE_KEY_SERVER>
Address = 10.8.0.1/24
ListenPort = 51820
PostUp = iptables -A FORWARD -i wg0 -j ACCEPT; iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
PostDown = iptables -D FORWARD -i wg0 -j ACCEPT; iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE

# Konfigurasi Klien 1
[Peer]
PublicKey = <ISI_PUBLIC_KEY_KLIEN>
AllowedIPs = 10.8.0.2/32

    Sesuaikan eth0 dengan nama interface jaringan publik di server Anda.

  4. 4. Aktifkan IP Forwarding & Firewall

    Buka file /etc/sysctl.conf dan hilangkan tanda komentar pada baris net.ipv4.ip_forward=1 agar server bisa meneruskan paket:

    sudo nano /etc/sysctl.conf

    Terapkan perubahan sysctl dan buka port WireGuard di firewall UFW:

    sudo sysctl -p
    sudo ufw allow 51820/udp
  5. 5. Aktifkan Service WireGuard

    Jalankan dan aktifkan WireGuard agar otomatis berjalan saat reboot:

    sudo wg-quick up wg0
    sudo systemctl enable wg-quick@wg0

    Untuk memverifikasi status koneksi dan peer, jalankan perintah: sudo wg

  6. 6. Pengujian Koneksi Klien

    File Konfigurasi Klien (client.conf):

    [Interface]
PrivateKey = <ISI_PRIVATE_KEY_KLIEN>
Address = 10.8.0.2/24
DNS = 1.1.1.1

[Peer]
PublicKey = <ISI_PUBLIC_KEY_SERVER>
Endpoint = IP_PUBLIC_SERVER:51820
AllowedIPs = 0.0.0.0/0

    Verifikasi Berhasil: Lakukan ping ke 10.8.0.1 dari Klien atau periksa IP publik lewat curl ifconfig.me untuk memastikan trafik terenkripsi melewati VPN.
