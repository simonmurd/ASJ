DNS Server (BIND9)

Linux dns-server 6.1.0-11-amd64 Debian 12 (Mobile & Tablet Friendly)
Gunakan tombol perintah cepat di bawah atau ketik submit-lab untuk verifikasi.

Cepat:
root@dns:~#
GNU nano 5.09 File: ...
Tips: Buka "Panduan" di atas jika butuh bantuan.

Panduan Praktikum

1. Instalasi

apt update apt install bind9 bind9utils dnsutils -y

2. Konfigurasi Zone

nano /etc/bind/named.conf.local

Salin / Ketik teks ini ke dalam Nano:

zone "smk.net" {
    type master;
    file "/etc/bind/db.smk";
};
zone "10.168.192.in-addr.arpa" {
    type master;
    file "/etc/bind/db.192";
};

3. Buat File Database

cp /etc/bind/db.local /etc/bind/db.smk cp /etc/bind/db.127 /etc/bind/db.192 nano /etc/bind/db.smk nano /etc/bind/db.192

4. Restart Layanan

systemctl restart bind9

5. Verifikasi Akhir

submit-lab
