CyberLab Pro SNMP, Cacti & Nagios

Tujuan Praktikum

  • Mengonfigurasi agen SNMP pada perangkat target (Managed Node).
  • Menginstal LAMP Stack, membuat Database Cacti, serta mengonfigurasi Poller Cron Job.
  • Mendefinisikan Host & Service Monitoring pada Nagios Core serta memverifikasi konfigurasi.

Instruksi Langkah Demi Langkah

  1. 1. Konfigurasi SNMP pada Perangkat Target

    Sebelum dipantau Cacti/Nagios, aktifkan service SNMP pada Linux Server target:

    A. Edit Konfigurasi SNMP Linux Server:

    sudo nano /etc/snmp/snmpd.conf

    Tambahkan/sesuaikan baris berikut:

    rocommunity public-monitoring 192.168.1.0/24
agentaddress udp:161

    B. Restart Service SNMP:

    sudo systemctl restart snmpd
  2. 2. Instalasi & Konfigurasi Cacti (Ubuntu Server)

    A. Install Dependency & Web Server LAMP Stack:

    sudo apt update
    sudo apt install apache2 mariadb-server php php-mysql php-snmp php-xml php-mbstring php-gd php-gmp rrdtool snmp snmpd -y

    B. Konfigurasi Database Cacti di MariaDB:

    sudo mysql 
    CREATE DATABASE cacti DEFAULT CHARACTER SET utf8 COLLATE utf8_unicode_ci;
GRANT ALL PRIVILEGES ON cacti.* TO 'cactiuser'@'localhost' IDENTIFIED BY 'PasswordKuat123!';
FLUSH PRIVILEGES;
EXIT;

    C. Install Package Cacti & Set Cron Job Poller:

    sudo apt install cacti -y

    Buka file cron Cacti:

    sudo nano /etc/cron.d/cacti

    Pastikan isinya:

    */5 * * * * www-data php /usr/share/cacti/site/poller.php > /dev/null 2>&1
  3. 3. Konfigurasi Host Monitoring di Nagios Core

    A. Tambahkan objek host pada file konfigurasi Nagios:

    sudo nano /usr/local/nagios/etc/objects/hosts.cfg 
    define host {
    use                     generic-switch
    host_name               Router-Core
    alias                   MikroTik Core Office
    address                 192.168.1.1
    hostgroups              switches
    check_command           check-host-alive
    max_check_attempts      5
    check_interval          1
    notification_interval   30
    notification_period     24x7
}

define service {
    use                     generic-service
    host_name               Router-Core
    service_description     PING Status
    check_command           check_ping!100.0,20%!500.0,60%
}

    B. Validasi Konfigurasi & Restart Nagios Service:

    sudo nagios -v /usr/local/nagios/etc/nagios.cfg
    sudo systemctl restart nagios
