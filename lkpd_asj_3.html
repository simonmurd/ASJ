Fokus: Keamanan Dasar Linux

Di sistem operasi Linux, tidak semua orang boleh mengubah file sistem. Hal ini untuk mencegah kerusakan sistem atau pencurian data.

  • Memahami konsep rwx (Read, Write, Execute).
  • Mengubah Hak Akses dengan `chmod` (Oktal & Simbolik).
  • Mengelola Kepemilikan (Owner/Group) dengan `chown` & `chgrp`.

Sensasi Kerja Admin Server

Sebagai IT Security & Admin Server di perusahaan, Anda bertanggung jawab penuh memastikan data sensitif seperti file gaji, database, dan file konfigurasi web tidak bisa dihapus atau disalin oleh sembarang karyawan. Kesalahan memberi permission bisa berakibat fatal!

Tabel Observasi CLI: Hak Akses & Kepemilikan

Pelajari fungsi setiap perintah di bawah ini dan catat hasilnya. (Beberapa perintah memerlukan hak akses Root).

10 Perintah Penting
No Perintah CLI Keamanan Deskripsi Fungsi Server Catatan Analisa Kamu
1 ls -l Menampilkan daftar file secara detail, termasuk melihat string hak akses (rwx), pemilik (owner), dan grup (group).
2 chmod 755 [nama_file] Mengubah hak akses (Pemilik bisa rwx, Grup & Others hanya r-x). Standar aman untuk direktori atau file script executable.
3 chmod 644 [nama_file] Mengubah hak akses (Pemilik bisa rw-, Grup & Others hanya r--). Standar aman untuk file dokumen biasa agar tidak bisa diubah orang lain.
4 chmod u+x [nama_file] Mengubah hak akses via metode simbolik (menambahkan hak eksekusi 'x' khusus untuk user/pemilik 'u').
5 chmod -R 775 [direktori] Mengubah hak akses secara rekursif (berlaku untuk folder tersebut beserta seluruh file dan sub-folder di dalamnya).
6 chown [user] [file] Mengubah kepemilikan user (owner) utama dari sebuah file atau direktori.
7 chgrp [group] [file] Mengubah kelompok/grup (group) yang diizinkan mengakses file atau direktori tersebut.
8 chown [user]:[group] [file] Jalan pintas (shortcut) untuk mengubah kepemilikan user dan grup sekaligus dalam satu baris perintah.
9 chown -R [user] [direktori] Mengubah kepemilikan (owner) secara rekursif pada sebuah folder besar beserta seluruh isinya ke bawah.
10 sudo [perintah] Mengeksekusi perintah dengan hak Superuser. Mengubah file sistem krusial wajib memakai ini agar tidak ditolak aksesnya (Permission Denied).
