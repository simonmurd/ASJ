CyberLab Pro BIND9 DNS Server

Tujuan Praktikum

  • Melakukan instalasi BIND9 dan utilities pengujinya di Linux.
  • Mendaftarkan Forward Zone dan Reverse Zone pada named.conf.local.
  • Membuat file record Forward Database (A Record & CNAME) dan Reverse Database (PTR).
  • Melakukan verifikasi sintaks zone dan pengujian DNS Server menggunakan perintah dig.

Instruksi Langkah Demi Langkah

  1. 1. Install BIND9 & Utilities

    Perbarui repositori dan pasang paket BIND9 beserta tools pengujinya:

    sudo apt update
    sudo apt install bind9 bind9utils bind9-doc -y
  2. 2. Deklarasikan Forward & Reverse Zone

    Buka file konfigurasi lokal BIND9 dan tambahkan definisi zone domain Anda:

    sudo nano /etc/bind/named.conf.local

    Tambahkan konfigurasi berikut:

    // Forward Zone (Domain ke IP)
zone "domainanda.com" {
    type master;
    file "/etc/bind/zones/db.domainanda.com";
};

// Reverse Zone (IP ke Domain - untuk subnet 192.168.10.x)
zone "10.168.192.in-addr.arpa" {
    type master;
    file "/etc/bind/zones/db.192";
};
  3. 3. Buat File Forward Zone Record

    Buat direktori dan isi file konfigurasi record untuk db.domainanda.com:

    sudo mkdir /etc/bind/zones
    sudo nano /etc/bind/zones/db.domainanda.com 
    $TTL    86400
@       IN      SOA     ns1.domainanda.com. admin.domainanda.com. (
                              2026090701 ; Serial (YYYYMMDDNN)
                                  604800 ; Refresh
                                   86400 ; Retry
                                 2419200 ; Expire
                                   86400 ) ; Negative Cache TTL
;
; Name Servers
@       IN      NS      ns1.domainanda.com.

; A Records (IP v4)
ns1     IN      A       192.168.10.10
@       IN      A       192.168.10.10
www     IN      A       192.168.10.10
mail    IN      A       192.168.10.10

; CNAME Record (Alias)
webmail IN      CNAME   mail.domainanda.com.
  4. 4. Buat File Reverse Zone Record (PTR)

    Buat file konfigurasi pemetaan balik IP ke Domain (db.192):

    sudo nano /etc/bind/zones/db.192 
    $TTL    86400
@       IN      SOA     ns1.domainanda.com. admin.domainanda.com. (
                              2026090701 ; Serial
                                  604800 ; Refresh
                                   86400 ; Retry
                                 2419200 ; Expire
                                   86400 ) ; Negative Cache TTL
;
; Name Servers
@       IN      NS      ns1.domainanda.com.

; PTR Records (Digit terakhir dari IP 192.168.10.10)
10      IN      PTR     domainanda.com.
10      IN      PTR     ns1.domainanda.com.
  5. 5. Validasi & Jalankan Service

    Periksa apakah ada kesalahan sintaks penulisan sebelum menjalankan layanan:

    sudo named-checkconf
    sudo named-checkzone domainanda.com /etc/bind/zones/db.domainanda.com
    sudo named-checkzone 10.168.192.in-addr.arpa /etc/bind/zones/db.192

    Jika tidak ada error, restart layanan BIND9:

    sudo systemctl restart bind9
    sudo systemctl enable bind9
  6. 6. Pengujian DNS Server

    Perintah Pengujian:

    dig @192.168.10.10 www.domainanda.com +short
    dig -x 192.168.10.10 @192.168.10.10 +short
