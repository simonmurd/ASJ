Fokus: Konfigurasi DHCP Server

DHCP (Dynamic Host Configuration Protocol) bertugas mendistribusikan alamat IP secara otomatis kepada klien. File utamanya berada di /etc/dhcp/dhcpd.conf.

  • Subnet & Range: Menentukan blok IP dan rentang IP yang akan disewakan.
  • Options: Memberikan informasi tambahan seperti Router (Gateway) dan DNS Server.
  • Lease Time: Durasi penyewaan IP sebelum klien harus memperbaruinya.

Sensasi Kerja Network Admin

Sebagai Administrator Jaringan, Anda bertugas mengonfigurasi layanan agar ratusan komputer klien di perusahaan dapat terhubung ke jaringan tanpa perlu disetting IP statis satu per satu. Anda juga harus memonitor log jika DHCP gagal berjalan.

Tabel Observasi CLI: Konfigurasi & Uji DHCP

Pelajari fungsi setiap perintah di bawah ini dan catat hasilnya untuk memahami siklus DHCP Server dan Klien.

10 Perintah Penting
No Perintah CLI Server/Klien Deskripsi Fungsi Sistem Catatan Analisa Kamu
1 nano /etc/dhcp/dhcpd.conf Membuka dan mengedit file konfigurasi utama DHCP server untuk menentukan subnet, range IP, router, dan DNS server.
2 systemctl restart isc-dhcp-server Memulai ulang layanan DHCP server. Wajib dilakukan setiap kali ada perubahan pada file konfigurasi dhcpd.conf agar diterapkan.
3 systemctl status isc-dhcp-server Mengecek status layanan DHCP server. Berfungsi memastikan apakah service berjalan normal (active/running) atau terjadi error (failed).
4 systemctl enable isc-dhcp-server Mengonfigurasi layanan DHCP agar otomatis menyala (autostart) ketika server melakukan proses booting atau dihidupkan ulang.
5 ip a Singkatan dari 'ip address'. Menampilkan seluruh antarmuka jaringan (seperti eth0/enp0s3) beserta IP address yang terpasang.
6 dhclient -r Perintah di sisi KLIEN untuk melepaskan (release) alamat IP dinamis yang sedang digunakan, membersihkan konfigurasi jaringan klien.
7 dhclient Perintah di sisi KLIEN untuk meminta (request/renew) IP address baru beserta konfigurasi gateway dan DNS dari DHCP server.
8 cat /var/lib/dhcp/dhcpd.leases Melihat file catatan (log) dari server mengenai alamat IP mana saja yang sedang disewakan beserta informasi MAC address klien.
9 tail -f /var/log/syslog Menampilkan log sistem secara real-time. Sangat ampuh digunakan saat troubleshooting jika service DHCP failed untuk melihat detail penyebab error.
10 ping [IP_Gateway] Menguji konektivitas jaringan. Jika klien DHCP sudah mendapat IP yang benar, ia seharusnya bisa menge-ping alamat IP gateway (server).
