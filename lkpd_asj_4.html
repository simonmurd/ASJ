CyberLab Pro Apache VHost & Nginx PHP-FPM

BAGIAN 1: Apache Virtual Host

  1. 1. Install Apache2
    sudo apt update
    sudo apt install apache2 -y
  2. 2. Buat Web Directory & Halaman Uji
    sudo mkdir -p /var/www/domainanda.com/html
    sudo chown -R $USER:$USER /var/www/domainanda.com/html
    echo "<h1>Situs Apache Berhasil Diaktifkan!</h1>" > /var/www/domainanda.com/html/index.html
  3. 3. Buat File Virtual Host

    Buka file /etc/apache2/sites-available/domainanda.com.conf menggunakan nano:

    sudo nano /etc/apache2/sites-available/domainanda.com.conf 
    <VirtualHost *:80>
    ServerAdmin admin@domainanda.com
    ServerName domainanda.com
    ServerAlias www.domainanda.com
    DocumentRoot /var/www/domainanda.com/html

    <Directory /var/www/domainanda.com/html>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/domainanda.com_error.log
    CustomLog ${APACHE_LOG_DIR}/domainanda.com_access.log combined
</VirtualHost>
  4. 4. Aktifkan Virtual Host & Reload Apache
    sudo a2ensite domainanda.com.conf
    sudo a2dissite 000-default.conf
    sudo apache2ctl configtest
    sudo systemctl reload apache2

BAGIAN 2: Nginx Server Block & PHP-FPM

  1. 1. Install Nginx & PHP-FPM
    sudo apt install nginx php-fpm -y
  2. 2. Buat Web Directory & File PHP
    sudo mkdir -p /var/www/situsku.com/html
    sudo chown -R www-data:www-data /var/www/situsku.com/html
    echo "<?php phpinfo(); ?>" | sudo tee /var/www/situsku.com/html/info.php
  3. 3. Buat Konfigurasi Server Block Nginx

    Buka file /etc/nginx/sites-available/situsku.com menggunakan nano:

    sudo nano /etc/nginx/sites-available/situsku.com 
    server {
    listen 80;
    listen [::]:80;

    server_name situsku.com www.situsku.com;
    root /var/www/situsku.com/html;
    index index.php index.html index.htm;

    location / {
        try_files $uri $uri/ =404;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php-fpm.sock;
    }

    location ~ /\.ht {
        deny all;
    }
}
  4. 4. Aktifkan & Uji Konfigurasi Nginx
    sudo ln -s /etc/nginx/sites-available/situsku.com /etc/nginx/sites-enabled/
    sudo nginx -t
    sudo systemctl reload nginx
