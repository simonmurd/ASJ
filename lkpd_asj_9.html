CyberLab Pro Mail Server (Postfix & Dovecot)

Tujuan Praktikum

  • Memasang Postfix (SMTP) dan Dovecot (POP3/IMAP) pada Linux.
  • Mengonfigurasi parameter domain dan direktori Maildir/ pada Postfix.
  • Mengaktifkan protokol serta otentikasi Dovecot ke Postfix.
  • Memahami kebutuhan DNS Record (A, MX, dan SPF Record) untuk Mail Server.

Langkah Konfigurasi

  1. 1. Update & Install Package Mail Server

    Memasang Postfix dan Dovecot. Jalankan perintah berikut pada terminal server Anda:

    sudo apt update
    sudo apt install postfix dovecot-imapd dovecot-pop3d -y

    Catatan: Saat instalasi Postfix, pilih Internet Site dan masukkan FQDN domain Anda (contoh: mail.domainanda.com).

  2. 2. Konfigurasi Postfix (SMTP)

    Edit file /etc/postfix/main.cf. Buka file konfigurasi utama dan sesuaikan parameter berikut:

    sudo nano /etc/postfix/main.cf 
    myhostname = mail.domainanda.com
alias_maps = hash:/etc/aliases
alias_database = hash:/etc/aliases
mydestination = $myhostname, domainanda.com, localhost.domainanda.com, localhost
relayhost = 
mynetworks = 127.0.0.0/8 [::1]/128
mailbox_size_limit = 0
recipient_delimiter = +
inet_interfaces = all
inet_protocols = all

# Format direktori penyimpanan pesan
home_mailbox = Maildir/
  3. 3. Konfigurasi Dovecot (POP3 & IMAP)

    Edit /etc/dovecot/dovecot.conf dan file pendukung.

    A. Aktifkan protokol di /etc/dovecot/dovecot.conf:

    sudo nano /etc/dovecot/dovecot.conf 
    protocols = imap pop3 lmtp

    B. Samakan direktori penyimpanan di /etc/dovecot/conf.d/10-mail.conf:

    sudo nano /etc/dovecot/conf.d/10-mail.conf 
    mail_location = maildir:~/Maildir

    C. Aktifkan autentikasi pengiriman melalui Postfix di /etc/dovecot/conf.d/10-master.conf:

    sudo nano /etc/dovecot/conf.d/10-master.conf 
    unix_listener /var/spool/postfix/private/auth {
  mode = 0666
  user = postfix
  group = postfix
}
  4. 4. Restart Service & Uji Koneksi

    Jalankan kembali kedua layanan untuk menerapkan konfigurasi:

    sudo systemctl restart postfix dovecot
    sudo systemctl enable postfix dovecot
  5. 5. Konfigurasi DNS Record (Wajib)

    Agar email tidak masuk ke folder SPAM atau ditolak server tujuan, buat record berikut di DNS Management Anda:

    A Record: mail.domainanda.com -> IP_Server_Anda
    MX Record: domainanda.com -> mail.domainanda.com (Priority: 10)
    TXT (SPF): "v=spf1 mx ~all"
