Fokus & Kompetensi Admin

  • Menginspeksi & membaca konfigurasi server (`cat`, `less`, `head`, `tail`).
  • Pencarian kata kunci & analisa error log secara cepat (`grep`).
  • Menyalin & backup file konfigurasi (`cp`, `cp -r`).
  • Memindahkan & mengubah nama file/direktori (`mv`).

Sensasi Kerja Network Engineer

Sebagai Administrator Sistem Jaringan, Anda akan sering bekerja via remote SSH layar hitam-putih. Anda harus lihai memeriksa log server dan mengedit konfigurasi tanpa mengandalkan software GUI berat.

Tabel Observasi Praktikum CLI: Manajemen File & Teks

Jalankan setiap perintah di bawah pada Terminal Interaktif di atas, lalu catat hasil output yang muncul ke dalam kolom yang tersedia.

10 Percobaan Praktikum
No Perintah CLI (Eksekusi di Terminal) Deskripsi Fungsi (Apa tujuan perintah ini?) Hasil Output Terminal (Catat di sini!)
1 cat /etc/hostname Menampilkan nama mesin (server) yang sedang kamu gunakan saat ini tanpa membuka editor.
2 cp /etc/hostname ~/host_cadangan.txt Menduplikasi file hostname ke direktori home (~) dengan nama baru sebagai backup.
3 mv ~/host_cadangan.txt ~/target_server.txt Mengganti nama file (rename) dari host_cadangan.txt menjadi target_server.txt.
4 head -n 4 /etc/passwd Mengintip tepat 4 baris paling atas dari file konfigurasi pengguna sistem.
5 tail -n 3 /etc/passwd Mengintip tepat 3 baris paling bawah dari file konfigurasi pengguna sistem.
6 grep "root" /etc/passwd Melakukan pemindaian cepat untuk mencari dan menampilkan baris yang hanya memiliki kata "root".
7 grep "bash" /etc/passwd Mencari akun/user mana saja di dalam server yang memiliki akses penuh ke terminal Linux (bash).
8 cat /etc/os-release Membaca file yang menyimpan informasi rahasia tentang versi sistem operasi Linux yang dipakai.
9 rm -rf ~/target_server.txt Menghapus file target_server.txt yang tadi dibuat secara permanen tanpa peringatan lanjutan.
10 less /etc/services Membuka file konfigurasi daftar port yang sangat panjang dalam mode baca interaktif (tekan q untuk keluar).
