CyberLab Pro DHCP Server Simulator

Tujuan Praktikum

  • Melakukan konfigurasi DHCP Server di Linux menggunakan paket isc-dhcp-server.
  • Menentukan interface jaringan dan parameter pool IP (subnet, range, router, reservation MAC).
  • Melakukan konfigurasi DHCP Server di Router MikroTik menggunakan wizard interaktif.
  • Memeriksa status service dan tabel sewa IP (leases).

Bagian A: DHCP Server Linux (Ubuntu/Debian)

  1. 1. Install Paket isc-dhcp-server
    sudo apt update
    sudo apt install isc-dhcp-server -y
  2. 2. Tentukan Interface Jaringan

    Edit file /etc/default/isc-dhcp-server:

    sudo nano /etc/default/isc-dhcp-server

    Ubah baris interface menjadi:

    INTERFACESv4="ens33"
  3. 3. Atur Pool Alamat IP & Parameter

    Edit file utama /etc/dhcp/dhcpd.conf:

    sudo nano /etc/dhcp/dhcpd.conf 
    subnet 192.168.10.0 netmask 255.255.255.0 {
  range 192.168.10.50 192.168.10.200;
  option domain-name-servers 8.8.8.8, 1.1.1.1;
  option domain-name "skil.local";
  option routers 192.168.10.1;
  option broadcast-address 192.168.10.255;
  default-lease-time 600;
  max-lease-time 7200;
}

host Printer-Office {
  hardware ethernet 00:11:22:33:44:55;
  fixed-address 192.168.10.25;
}
  4. 4. Restart & Uji Status Service
    sudo systemctl restart isc-dhcp-server
    sudo systemctl status isc-dhcp-server

Bagian B: DHCP Server di Router MikroTik

  1. 1. Atur IP Address Interface Router

    Pindah ke tab [admin@MikroTik] di sebelah kanan, lalu jalankan:

    /ip address add address=192.168.20.1/24 interface=ether2
  2. 2. Jalankan DHCP Setup Wizard
    /ip dhcp-server setup

    Isi parameter wizard berikut saat diminta:

    • Interface: ether2
    • DHCP Address Space: 192.168.20.0/24
    • Gateway for Network: 192.168.20.1
    • Addresses to Give Out: 192.168.20.10-192.168.20.100
    • DNS Servers: 8.8.8.8, 8.8.4.4
    • Lease Time: 03:00:00
  3. 3. Cek Daftar Sewa IP (Leases)
    /ip dhcp-server lease print
