CyberLab Pro Webmin & cPanel/WHM

Tujuan Praktikum

  • Konfigurasi Webmin di Linux (Debian/Ubuntu).
  • Penambahan repositori & GPG Key resmi Webmin.
  • Konfigurasi Firewall UFW Port 10000/tcp.
  • Konfigurasi cPanel/WHM di Linux (AlmaLinux/Ubuntu).
  • Pengaturan FQDN Hostname dan eksekusi skrip installer cPanel.

Instruksi Langkah Demi Langkah

BAGIAN 1: KONFIGURASI WEBMIN
  1. 1. Menambahkan Repository Webmin

    Persiapan repository & dependency serta tambahkan kunci GPG resmi Webmin ke sistem:

    sudo apt update
    sudo apt install software-properties-common apt-transport-https wget -y
    wget -q http://www.webmin.com/jcameron-key.asc -O- | sudo apt-key add -
    sudo add-apt-repository "deb [arch=amd64] http://download.webmin.com/download/repository sdirect distribution"
  2. 2. Menginstall Webmin

    Jalankan perintah instalasi Webmin melalui package manager (Webmin akan otomatis berjalan di Port 10000):

    sudo apt update
    sudo apt install webmin -y
  3. 3. Membuka Port Webmin (UFW Firewall)

    Izinkan trafik lalu lintas data masuk ke Port 10000 Webmin:

    sudo ufw allow 10000/tcp
    sudo ufw reload
  4. 4. Login ke Dashboard Webmin

    Buka browser di Client Simulator lalu akses:

    https://192.168.1.100:10000

    Masuk menggunakan kredensial akun root server.

BAGIAN 2: KONFIGURASI CPANEL / WHM
Prasyarat Penting cPanel: Sistem operasi harus bersih (Clean Install) tanpa web server/MySQL pra-install, serta membutuhkan FQDN Hostname yang valid.
  1. 1. Set Hostname Server FQDN

    Atur hostname server menggunakan Fully Qualified Domain Name:

    hostnamectl set-hostname server.domainanda.com
  2. 2. Download & Eksekusi Installer

    Jalankan skrip instalasi resmi cPanel dari terminal:

    cd /home && curl -o latest -L https://secured.cpanel.net/latest && sh latest
  3. 3. Akses WHM Pertama Kali

    Buka browser di Client Simulator lalu akses link aktivasi WHM:

    https://192.168.1.100:2087

    Masuk sebagai root lalu selesaikan Initial Setup Wizard (Email Admin, NameServer, dan Lisensi).
