CyberLab Pro Samba File Server

Tujuan Praktikum

  • Memahami instalasi Samba File Server di sistem operasi Linux.
  • Menyiapkan folder share dan mengonfigurasi izin akses (read/write).
  • Mendaftarkan akun user Linux ke dalam kredensial Samba.
  • Mengonfigurasi file /etc/samba/smb.conf, Firewall, dan pengujian akses client.

Instruksi Langkah Demi Langkah

  1. Langkah 1: Instalasi Paket Samba

    Perbarui indeks paket repositori server, lalu install paket samba.

    sudo apt update
    sudo apt install samba -y

    Verifikasi:

    sudo systemctl status smbd

    Jalankan perintah di atas untuk memastikan service Samba sudah berjalan.

  2. Langkah 2: Menyiapkan Folder Share

    Buat folder khusus yang akan dibagikan di dalam jaringan, lalu atur hak aksesnya agar dapat dibaca dan ditulis (read/write).

    sudo mkdir -p /srv/samba/data
    sudo chmod 777 /srv/samba/data
  3. Langkah 3: Pembuatan User Samba

    Samba membutuhkan akun user sistem Linux yang kemudian didaftarkan ke dalam database kredensial Samba.

    sudo adduser siswa
    sudo smbpasswd -a siswa

    Catatan: Password untuk smbpasswd bisa disamakan atau dibedakan dengan password login Linux siswa.

  4. Langkah 4: Konfigurasi File /etc/samba/smb.conf

    Buka file konfigurasi utama Samba menggunakan text editor nano:

    sudo nano /etc/samba/smb.conf

    Gulir ke paling bawah file, lalu tambahkan baris konfigurasi blok share berikut:

    [data_siswa]
path = /srv/samba/data
browseable = yes
read only = no
valid users = siswa
    Penjelasan Konfigurasi:
    • [data_siswa]: Nama folder share yang akan terlihat oleh komputer Client.
    • path: Lokasi direktori fisik di dalam server.
    • browseable = yes: Folder dapat terlihat saat dicari di jaringan.
    • read only = no: Mengizinkan Client membuat, mengubah, atau menghapus file (Writeable).
    • valid users = siswa: Mengunci akses folder hanya untuk user siswa.

    Tekan Ctrl + O, lalu Enter untuk menyimpan, dan Ctrl + X untuk keluar.

  5. Langkah 5: Konfigurasi Firewall & Restart Service

    Izinkan lalu lintas data Samba pada UFW Firewall, lalu restart service Samba (smbd).

    sudo ufw allow samba
    sudo systemctl restart smbd
  6. 4. PENGUJIAN KONEKSI (TESTING)

    A. Pengujian dari Client Windows

    1. Tekan tombol kombinasi Win + R pada keyboard untuk membuka jendela Run.
    2. Ketik alamat IP Server dengan awalan double backslash:
      \\IP_Server_Kamu
      (Contoh: \\192.168.1.100)
    3. Tekan Enter.
    4. Saat muncul pop-up permintaan kredensial (Network Credentials):
      • Username: siswa
      • Password: (password Samba yang dibuat pada langkah 3)
    5. Buka folder data_siswa.
    6. Uji Coba: Buat file teks atau folder baru di dalamnya untuk memastikan fungsi read/write bekerja.

    B. Pengujian dari Client Linux

    1. Buka File Manager pada PC Client Linux.
    2. Pilih menu Other Locations / Connect to Server.
    3. Masukkan URL berikut:
      smb://IP_Server_Kamu/data_siswa
    4. Masukkan username siswa dan password Samba saat diminta.
