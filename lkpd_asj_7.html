File Server (Samba)

Linux file-server 6.1.0-11-amd64 Debian 12
Gunakan panduan (buku hijau) dan selesaikan konfigurasi Samba. Ketik submit-lab untuk verifikasi akhir.

Cepat:
root@debian:~#
GNU nano 5.09 File: ...
Tips: Tambahkan konfigurasi direktori share di baris paling bawah.

Panduan Praktikum Samba

1. Instalasi Samba

sudo apt update sudo apt install samba -y

2. Siapkan Folder Share

sudo mkdir -p /srv/samba/data sudo chmod 777 /srv/samba/data

3. Buat User Samba (misal: siswa)

sudo adduser siswa sudo smbpasswd -a siswa

4. Konfigurasi smb.conf

sudo nano /etc/samba/smb.conf

Tambahkan baris berikut di paling bawah file Nano:

[data_siswa]
path = /srv/samba/data
browseable = yes
read only = no
valid users = siswa

5. Firewall (UFW) & Restart

sudo ufw allow samba sudo systemctl restart smbd
