FTP Server (vsftpd)

Linux ftp-server 6.1.0-11-amd64 Debian 12
Gunakan panduan (buku hijau) dan selesaikan konfigurasi FTP. Ketik submit-lab untuk verifikasi akhir.

Cepat:
root@ftp:~#
GNU nano 5.09 File: ...
Tips: Hapus tanda '#' dan tambahkan konfigurasi sesuai panduan.

Panduan Praktikum FTP

1. Instalasi vsftpd

sudo apt update sudo apt install vsftpd -y

2. Konfigurasi vsftpd.conf

sudo nano /etc/vsftpd.conf

Ubah atau tambahkan baris berikut di Nano:

listen=NO
listen_ipv6=YES
anonymous_enable=NO
local_enable=YES
write_enable=YES
chroot_local_user=YES

pasv_enable=YES
pasv_min_port=40000
pasv_max_port=50000
user_sub_token=$USER
local_root=/home/$USER/ftp

3. User & Folder (misal: siswa_ftp)

sudo adduser siswa_ftp sudo mkdir /home/siswa_ftp/ftp sudo chown root:root /home/siswa_ftp/ftp sudo chmod 755 /home/siswa_ftp/ftp sudo mkdir /home/siswa_ftp/ftp/upload_dir sudo chown siswa_ftp:siswa_ftp /home/siswa_ftp/ftp/upload_dir

4. Firewall (UFW) & Restart

sudo ufw allow 20/tcp sudo ufw allow 21/tcp sudo ufw allow 40000:50000/tcp sudo ufw reload sudo systemctl restart vsftpd
