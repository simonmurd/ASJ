CyberLab Pro vsftpd FTP

Tujuan Praktikum

  • Memahami instalasi FTP Server (vsftpd).
  • Mengonfigurasi mode pasif, hak upload, dan chroot isolation.
  • Mengatur user FTP dan hak akses direktori khusus.
  • Konfigurasi UFW Firewall dan pengujian koneksi via FileZilla Client.

Instruksi Langkah Demi Langkah

  1. Langkah 1: Instalasi Paket vsftpd

    Perbarui indeks paket repositori server, lalu install paket vsftpd (Very Secure FTP Daemon).

    sudo apt update
    sudo apt install vsftpd -y
    sudo systemctl status vsftpd
  2. Langkah 2: Konfigurasi Utama vsftpd

    Buka file konfigurasi utama vsftpd menggunakan text editor nano:

    sudo nano /etc/vsftpd.conf

    Sesuaikan atau tambahkan baris-baris konfigurasi berikut di dalam file tersebut:

    # Mengatur listener jaringan (IPv6 / IPv4)
listen=NO
listen_ipv6=YES

# Keamanan Akses User
anonymous_enable=NO
local_enable=YES
write_enable=YES

# Mengunci User di dalam Folder Home-nya (Chroot)
chroot_local_user=YES

# Mode Pasif dan Lokasi Root FTP
pasv_enable=YES
pasv_min_port=40000
pasv_max_port=50000
user_sub_token=$USER
local_root=/home/$USER/ftp
    Penjelasan Konfigurasi:
    • anonymous_enable=NO: Melarang pengguna anonim tanpa login.
    • write_enable=YES: Mengizinkan upload dan perubahan file.
    • chroot_local_user=YES: Mengunci user agar tidak bisa menjelajah ke folder sistem lain di luar folder FTP-nya.
    • pasv_min_port & pasv_max_port: Port pasif untuk mentransfer data.
  3. Langkah 3: Pembuatan User dan Pengaturan Direktori FTP

    Secara sistem, vsftpd melarang user memiliki hak akses tulis (write permission) pada root folder chroot demi keamanan. Karena itu, buat struktur folder khusus:

    sudo adduser siswa_ftp
    sudo mkdir /home/siswa_ftp/ftp
    sudo chown root:root /home/siswa_ftp/ftp
    sudo chmod 755 /home/siswa_ftp/ftp
    sudo mkdir /home/siswa_ftp/ftp/upload_dir
    sudo chown siswa_ftp:siswa_ftp /home/siswa_ftp/ftp/upload_dir
  4. Langkah 4: Konfigurasi Firewall & Restart Service

    Buka port FTP (port command 20, 21) dan rentang port pasif (40000-50000) pada UFW Firewall, kemudian restart service vsftpd.

    sudo ufw allow 20/tcp
    sudo ufw allow 21/tcp
    sudo ufw allow 40000:50000/tcp
    sudo ufw reload
    sudo systemctl restart vsftpd
  5. Pengujian Koneksi (Testing FileZilla)

    1. Buka FileZilla di Client:

    • Host: 192.168.1.100
    • Username: siswa_ftp
    • Password: 123456 (password saat adduser)
    • Port: 21

    2. Pengujian Upload: Drag file ke folder upload_dir.

    3. Pengujian Chroot Isolation: Coba akses folder luar (misal /etc). Sistem harus menolak akses.
