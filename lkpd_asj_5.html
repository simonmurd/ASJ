Teori Singkat & Tujuan Praktikum

  • Memahami instalasi DNS Server (BIND9).
  • Mengonfigurasi Forward & Reverse Zone.
  • Manajemen file database db.smk dan db.192.
  • Meningkatkan efisiensi kerja menggunakan CLI.

Panduan Praktikum

  1. 1. Instalasi
    apt update apt install bind9 bind9utils dnsutils -y
  2. 2. Konfigurasi Zone
    nano /etc/bind/named.conf.local 
    zone "smk.net" {
    type master;
    file "/etc/bind/db.smk";
};
zone "10.168.192.in-addr.arpa" {
    type master;
    file "/etc/bind/db.192";
};
  3. 3. Buat File Database
    cp /etc/bind/db.local /etc/bind/db.smk cp /etc/bind/db.127 /etc/bind/db.192 nano /etc/bind/db.smk nano /etc/bind/db.192
  4. 4. Restart Layanan
    systemctl restart bind9
  5. 5. Verifikasi Akhir
    submit-lab
