CyberLab Pro BIND9 DNS

Tujuan Praktikum

  • Memahami instalasi DNS Server (BIND9).
  • Mengonfigurasi Forward & Reverse Zone.
  • Manajemen file database db.smk dan db.192.

Instruksi

  1. 1. Update & Instalasi BIND9
    apt update
    apt install bind9 bind9utils dnsutils -y
  2. 2. Konfigurasi Zone
    nano /etc/bind/named.conf.local 
    zone "smk.net" {
    type master;
    file "/etc/bind/db.smk";
};
zone "10.168.192.in-addr.arpa" {
    type master;
    file "/etc/bind/db.192";
};
  3. 3. Salin File Database
    cp /etc/bind/db.local /etc/bind/db.smk
    cp /etc/bind/db.127 /etc/bind/db.192
  4. 4. Edit Database & Restart
    nano /etc/bind/db.smk

    * Ubah A record IP 127.0.0.1 menjadi 192.168.10.1

    nano /etc/bind/db.192

    * Ubah localhost. menjadi smk.net.

    systemctl restart bind9
