CyberLab Pro Network & AD DS

Tujuan Praktikum

  • Konfigurasi IP Static di Ubuntu Server menggunakan Netplan.
  • Menerapkan & menguji status antarmuka jaringan di Linux.
  • Konfigurasi Static IP dan DNS di Windows Server via PowerShell.
  • Instalasi AD DS dan Promosi Server menjadi Domain Controller.

1. Ubuntu Server (Netplan)

  1. Langkah 1: Identifikasi Interface Jaringan

    Periksa nama kartu jaringan aktif (contoh: ens33):

    ip link show
  2. Langkah 2: Konfigurasi IP Static Netplan

    Buka file konfigurasi YAML Netplan:

    sudo nano /etc/netplan/00-installer-config.yaml

    Isikan struktur YAML berikut ke dalam editor:

    network:
  version: 2
  renderer: networkd
  ethernets:
    ens33:
      dhcp4: no
      addresses:
        - 192.168.10.10/24
      routes:
        - to: default
          via: 192.168.10.1
      nameservers:
        addresses:
          - 8.8.8.8
          - 1.1.1.1
  3. Langkah 3: Terapkan Konfigurasi Network

    Uji sintaks YAML dan terapkan perubahan IP:

    sudo netplan apply
    ip a show ens33

2. Windows Server (Active Directory)

  1. Langkah 1: Atur Static IP Address & DNS

    Jalankan perintah PowerShell berikut:

    New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress "192.168.10.10" -PrefixLength 24 -DefaultGateway "192.168.10.1"
    Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses ("127.0.0.1", "8.8.8.8")
  2. Langkah 2: Install Active Directory Domain Services

    Pasang fitur AD DS beserta tools manajemennya:

    Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools
  3. Langkah 3: Promosi Server Menjadi Domain Controller

    Buat Forest baru (contoh: domainanda.local):

    Install-ADDSForest -DomainName "domainanda.local" -SafeModeAdministratorPassword (ConvertTo-SecureString "PasswordKuat123!" -AsPlainText -Force) -InstallDns:$true -Force:$true

Topologi Server Jaringan

Ubuntu Server (Netplan) 192.168.10.10/24 Interface: ens33
Gateway Router 192.168.10.1
Windows Server (AD DS) 192.168.10.10/24 Domain: domainanda.local
