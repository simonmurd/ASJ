Web Server (Apache2)

Linux web-server 6.1.0-11-amd64 Debian 12
Gunakan panduan (buku hijau) dan selesaikan konfigurasi Apache2. Ketik submit-lab untuk verifikasi akhir.

Cepat:
root@debian:~#
GNU nano 5.09 File: ...
Tips: Ubah tulisan HTML untuk membuat halaman web versimu sendiri.

Panduan Web Server

1. Instalasi Apache2

sudo apt update sudo apt install apache2 -y

2. Ubah Halaman Web Default

sudo nano /var/www/html/index.html

Ubah tulisan "It works!" di dalam editor nano dengan teks apa saja (contoh: "Halo Dunia!"). Simpan jika sudah.

3. Konfigurasi Firewall (UFW)

Izinkan lalu lintas HTTP (Port 80) melewati firewall.

sudo ufw allow 80/tcp

4. Restart & Uji Coba

sudo systemctl restart apache2 curl http://localhost
