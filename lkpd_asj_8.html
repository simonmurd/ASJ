CyberLab Pro Apache Web Server

Tujuan Praktikum

  • Memahami instalasi Apache Web Server di sistem operasi Linux.
  • Mengubah halaman web default di direktori /var/www/html/index.html.
  • Mengonfigurasi UFW Firewall untuk mengizinkan lalu lintas web pada Port 80 (HTTP).
  • Melakukan pengujian koneksi lokal (curl) dan pengujian dari Client Browser.

Instruksi Langkah Demi Langkah

  1. Langkah 1: Instalasi Paket Apache2

    Perbarui indeks paket repositori server, lalu install paket apache2.

    sudo apt update
    sudo apt install apache2 -y

    Verifikasi:

    sudo systemctl status apache2

    Jalankan perintah di atas untuk memastikan service web server sudah aktif (active/running).

  2. Langkah 2: Mengubah Halaman Web Default

    Secara default, Apache2 menyimpan file halaman utama pada direktori /var/www/html/index.html. Buka file tersebut dengan text editor nano:

    sudo nano /var/www/html/index.html

    Hapus atau ganti isi file tersebut dengan kode HTML sederhana berikut (atau tulisan sesuai instruksi):

    <!DOCTYPE html><html><head>
    <title>Web Server Apache</title></head><body>
    <h1>Halo Dunia!</h1>
    <p>Selamat, Apache Web Server berhasil dikonfigurasi.</p></body></html>

    Tekan Ctrl + O, lalu Enter untuk menyimpan, dan Ctrl + X untuk keluar.

  3. Langkah 3: Konfigurasi Firewall (UFW)

    Izinkan lalu lintas data web pada Port 80 (HTTP) agar halaman web dapat diakses oleh komputer di luar server.

    sudo ufw allow 80/tcp

    Catatan: Kamu juga bisa menggunakan perintah profil dari UFW: sudo ufw allow 'Apache'.

  4. Langkah 4: Restart Service & Uji Coba Lokal

    Muat ulang service Apache2 agar semua perubahan diterapkan, lalu lakukan pengujian pertama di dalam server menggunakan tool curl.

    sudo systemctl restart apache2
    curl http://localhost

    Hasil yang Diharapkan: Terminal akan menampilkan struktur file HTML atau teks "Halo Dunia!" yang sebelumnya sudah diisikan pada file index.html.

  5. 4. PENGUJIAN KONEKSI (TESTING)

    A. Pengujian dari Browser Client

    1. Buka aplikasi Web Browser (Google Chrome, Firefox, atau Edge) pada PC Client (Tab Client simulator di sebelah kanan).
    2. Masukkan alamat IP Server pada kolom URL / address bar:
      http://IP_Server_Kamu
      (Contoh: http://192.168.1.100)
    3. Tekan Enter.

    Hasil yang Diharapkan: Tampil halaman web dengan tulisan "Halo Dunia!".
